⚡ Key Features

Zero Configuration

No API keys needed. Public Avaturn Creator works out-of-box.

Standard Skeleton

Avaturn uses Humanoid bones. All animations play without re-targeting.

Client-Side Only

No backend needed. Browser ↔ Avaturn via postMessage.

Graceful Fallback

If Avaturn fails, reverts to pre-loaded avatars instantly.

🔐 Security

  • ✓ Origin validation — Only Avaturn domains accepted
  • ✓ No credentials stored — No API keys in code
  • ✓ Selfie stays local — Not uploaded to backend
  • ✓ Public assets only — GLB URLs cacheable, not sensitive
